# Sistema de Control de Vuelo ESP32 

Proyecto universitario desarrollado con ESP32 para el control de Roll y Pitch mediante sensor MPU6050 GY-521.

Cuenta con una capa de abstraccion para emplear un filtro kalman de 1 dimension para llevar a cabo la fusion de sensores del modulo GY-521; aceleromtro y giroscopio.
